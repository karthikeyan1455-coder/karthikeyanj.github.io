# Karthikeyan J – Portfolio

Run locally: open index.html in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000
Edit content: change the text in index.html (sections are marked with comments); colours and fonts are the variables at the top of style.css.
Profile photo: put profile.jpg in this folder, then in index.html replace `<div class="photo" id="photo">[Add Profile Photo]</div>` with `<div class="photo"><img src="profile.jpg" alt="Karthikeyan J"></div>`.
Deploy free: GitHub Pages (push files to a repo, Settings > Pages > Deploy from branch > main /root) or Netlify (drag the folder onto app.netlify.com/drop).
Real contact form: sign up with Formspree or Netlify Forms and replace the mailto code in script.js with a fetch() POST to their endpoint.
